# Portfolio Website

A modern, responsive portfolio website showcasing projects, skills, experience, and services.

## Features

✅ **Hero/Landing Section** - Strong first impression with name, title, and tagline  
✅ **About Me** - Background, skills, and professional drive  
✅ **Projects/Work** - Showcases with images, descriptions, technologies, and links  
✅ **Skills/Technologies** - Visual representation of technical abilities  
✅ **Experience/Resume** - Work history, education, achievements with downloadable PDF  
✅ **Contact Section** - Email, social links, and contact form  
✅ **Services** - Freelancing services offered  
✅ **Testimonials** - Client and colleague quotes  
✅ **Availability Status** - Open to work indicator  

## Design Features

- Clean, focused layout
- Fast loading with optimized structure
- Fully mobile responsive
- Clear navigation
- Consistent branding
- Dark mode support
- Smooth animations and transitions

## Setup Instructions

1. **Add Your Resume PDF**: 
   - Create a PDF file named `resume.pdf` in the project root
   - Or update the `downloadCV()` function in `portfolio.js` to point to your actual resume file

2. **Update Project Links**:
   - Replace placeholder project links with your actual GitHub repos and live demo URLs
   - Update project images (currently using placeholder images)

3. **Customize Content**:
   - Update personal information in `portfolio.html`
   - Add your actual work experience and education
   - Update skills and proficiency levels
   - Add real testimonials from clients/colleagues
   - Update social media links in the contact section

4. **Add Project Images**:
   - Replace placeholder images with actual project screenshots
   - Recommended size: 400x250px
   - Store images in an `images` folder or use external URLs
